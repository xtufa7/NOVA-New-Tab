# Optional Windows bridge dependencies

The bundled executable contains Python 3.12 (PSF license), Tcl/Tk (Tcl/Tk license), psutil 7.2.2 (BSD-3-Clause), PyWinRT 3.2.1 packages (MIT), and the PyInstaller 6.22.3 bootloader (GPL with the exception permitting distribution of bundled applications under their own license). These dependencies retain their respective licenses. Dependency license files accompany the executable where included in the installed distributions. CAVA is not bundled. The extension contains no runtime Python or remote scripts.

Source and executable build steps: `nova_bridge.py`, `launcher.py`, `requirements.txt`, `build.ps1`.
