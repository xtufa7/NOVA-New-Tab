# رفع NØVA 3.0.0 إلى Chrome Web Store

ملف الرفع الجاهز داخل هذا الإصدار: **NOVA-3.0.0-store.zip**.
ارفع هذا ZIP مباشرة؛ `manifest.json` موجود في جذره. لا ترفع مجلد المشروع أو حزمة GitHub. حزمة المتجر تحتوي ملفات الإضافة فقط. سكربت PowerShell اختياري في حزمة منفصلة، ويجب الإفصاح عن التكامل عند تعبئة الخصوصية.

## الخطوات

1. افتح [لوحة المطورين](https://chrome.google.com/webstore/devconsole)، وسجّل حساب مطور. توجد رسوم تسجيل مرة واحدة؛ راجع المبلغ وأهلية البلد في شاشة حسابك. [التسجيل الرسمي](https://developer.chrome.com/docs/webstore/register).
2. اختر New item وارفع `NOVA-3.0.0-store.zip`. عند تحديث إضافة منشورة، افتح عنصرها الحالي واستخدم Upload new package بدل إنشاء عنصر جديد. [تعليمات النشر](https://developer.chrome.com/docs/webstore/publish/).
3. أكمل Store listing: الاسم NØVA، ووصف واضح لصفحة New Tab المخصصة والطرفية والموسيقى وأدوات المتصفح الاختيارية. لا تدّعِ أن NØVA تابع لـ Spotify أو TikTok أو Catppuccin.
4. أرفق أيقونة 128×128 من `store/icons/128.png`، ولقطتي 1280×800 جاهزتين في `docs/images/store/newtab-1280x800.png` و`music-1280x800.png`، وصورة ترويجية صغيرة جاهزة `promo-440x280.png`. يمكن تجهيز الصورة الترويجية من التصميم الحقيقي؛ لا تغيّر لقطة المنتج لتوحي بميزات غير موجودة. [متطلبات الصور](https://developer.chrome.com/docs/webstore/images).
5. انشر `PRIVACY_POLICY.md` على رابط HTTPS عام، مع مراجعة بيانات التواصل والتاريخ، وأدخل الرابط في لوحة المطور. ملف Markdown المحلي وحده لا يكفي كرابط سياسة.
6. أكمل Privacy practices وتبريرات الأذونات أدناه. أجب No عن Remote code: كل JavaScript محزّم محليًا؛ تنزيل الخطوط وJSON للكلمات هو بيانات. اكشف بدقة عن بيانات سجل المواقع، عناوين التابات، محتوى Spotify المقروء، والبيانات المرسلة لـ LRCLIB؛ لا تختَر «لا بيانات» دون مراجعة أنواع البيانات في النموذج. [حقول الخصوصية](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy).
7. اختر التوزيع المناسب، واحفظ المسودة ثم Submit for review. المراجعة قد تطلب تعديل وصف الغرض أو الأذونات؛ بناء ZIP لا يعني قبول المتجر.

## نص الغرض الواحد المقترح

“NØVA provides a customizable new-tab workspace for launching searches and links, managing local workspaces, and using optional music and browsing tools from the same workspace.”

يجب أن يطابق الوصف المنتج الفعلي. الزر الجانبي والموسيقى والحماية ميزات اختيارية تحتاج وصفًا واضحًا؛ القرار النهائي حول توافق النطاق يعود لمراجعة المتجر.

## تبرير الأذونات

| الإذن | الاستخدام الفعلي |
| --- | --- |
| storage | إعدادات وملاحظات وملفات تعريف محفوظة محليًا؛ حالة الجلسة أثناء التشغيل. |
| alarms | تطبيق قواعد الثيم التلقائية عند حدود الجدول المحلي دون إبقاء الخدمة قيد التشغيل. |
| sidePanel | عرض مدير التابات في اللوحة الجانبية في Chromium. |
| sessions — optional | عرض التابات المغلقة حديثًا وإعادة فتحها بطلب المستخدم. |
| tabGroups — optional | إنشاء المجموعات الأصلية وإدارتها عند دعم المتصفح. |
| offscreen | متابعة موسيقى الملفات المحلية عند إغلاق تبويب New Tab. |
| activeTab | التقاط معاينة التبويب الذي استدعى المستخدم منه زر الإضافة. |
| declarativeNetRequest | قواعد محلية لحجب نقاط تتبع معروفة عند تفعيل الحماية؛ وتعديل Referer مؤقت لطلب صورة Guns العام المحدد من الإضافة عند تفعيل المزامنة. لا قراءة لمحتوى الطلبات. هو إذن أساسي لأن Chromium لا يقبل وضعه في optional_permissions. |
| scripting | تحميل كود محلي لثيم المواقع والمفتش وFocus على النطاقات المصرح بها، إضافةً للزر الجانبي وSpotify وتثبيت الفيديو ومزامنة صورة Guns الاختيارية. |
| tabs — optional | عناوين وروابط التابات للأدوات والجلسات والنافذة العائمة. |
| history — optional | أداة Recent sites التي يفعلها المستخدم. |
| nativeMessaging — optional | ربط سكربت PowerShell الذي يسجله المستخدم يدويًا لقراءة بيانات Spotify على ويندوز؛ تشغيله خارج نطاق الإضافة موضح بالتحذير الأحمر، وتعطيله يفصل العملية. |
| tabCapture — optional | بث معاينة مرئية لتبويب محدد بإجراء المستخدم. |
| HTTP/HTTPS — optional hosts | ثيم المواقع والمفتش وFocus والزر الجانبي تعمل فقط على المواقع المصرح بها؛ يمكن اختيار نطاق واحد أو جميع المواقع. محرك الثيم يفحص بنية DOM والألوان محليًا، بما فيها الإطارات ذات الصلاحية، ولا يجمع نصوص أو بيانات حقول المستخدم. |
| open.spotify.com | عنوان الأغنية والفنان والمدة والموضع وحالة التشغيل، لعرض الكلمات. لا قراءة للرموز أو كلمات المرور. |
| fonts.googleapis.com / fonts.gstatic.com | تنزيل الخط الذي يطلبه المستخدم بالاسم ثم تخزينه محليًا. |
| lrclib.net | إرسال عنوان الأغنية والفنان والمدة لجلب كلمات متزامنة تلقائيًا عند تشغيل أغنية بينما online lyrics مفعّل؛ يمكن إطفاؤه من Music. |
| guns.lol / r2.guns.lol | زيارة ملف المطور العام وقراءة رابط صورته وتنزيلها إذا بقيت المزامنة مفعّلة من إعدادات سابقة؛ بدون بيانات تسجيل دخول. |

لا توجد إعلانات أو تحليلات أو خوادم خاصة بـ NØVA. إرسال استعلام كلمات الأغنية لطرف ثالث يجب الإفصاح عنه رغم عدم وجود خادم للمنتج.

## اختبار قبل الإرسال

حمّل مجلد `store` عبر Load unpacked على بروفايل تجريبي وافحص New Tab والإعدادات. تحقق من عدم ظهور تحذير DNR القديم. اختبر طلب الأذونات عند تفعيل كل ميزة، وتعطيلها، والاستثناءات. اختبر Pin من شريط المتصفح على الموقع الحقيقي في Helium/Chromium؛ قد يُمنع التقاط فيديو محمي. جرّب ملف إعدادات قديم قبل نشر التحديث.

حافظ على نفس ID عند تحديث العنصر المنشور. تثبيت المتجر منفصل عن نسختك المحلية غير المنشورة؛ صدّر إعداداتك قبل الانتقال، استخدم Export full backup لنقل الفيديو والأغاني والخطوط والأيقونات فعليًا، ثم Import full backup على التثبيت الجديد. JSON ينقل المراجع فقط.

هذا الدليل راجع التوثيق الرسمي بتاريخ 2026-10-11. لا يتضمن رفعًا أو نشرًا تلقائيًا، ولم تُرسل الإضافة للمراجعة.


Firefox وZen لهما بناء مختلف؛ لا ترفع حزمتهما لمتجر Chrome. [دليل Mozilla](BROWSERS_AR.md).

إصدار 3.0.0 يطلب وصول Spotify Web وLRCLIB أثناء التثبيت لتشغيل الكلمات تلقائيًا. تحديث الإضافة قد يتطلب قبول الصلاحيات الجديدة مرة واحدة. تصريح websiteContent في نسخة Firefox مطلوب أثناء التثبيت، ولا يوجد طلب data_collection إلى Chromium.
