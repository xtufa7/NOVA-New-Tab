# NØVA Privacy Policy

Effective date: 2026-10-07. Version: 1.5.6. Publisher/contact: [xtufa7 on GitHub](https://github.com/xtufa7).

NØVA contains no advertising, analytics, telemetry or publisher-operated data server. It does not sell user data or use it for advertising. A New Tab with no playing song makes no external requests. With the default Spotify/lyrics connection enabled, detected song metadata triggers requests to LRCLIB; this can be disabled in Music.

Settings, branding, notes, command history, sessions, themes, workspaces and tab customization are stored locally in browser storage. User-selected wallpaper images/videos, music, covers, fonts, favicons and cached avatars are stored in local IndexedDB. Command history can be disabled or cleared. JSON exports contain settings and media references. User-initiated full `.nova` exports also contain the referenced local media bytes, with integrity hashes. Exported files are under the user's control and can include personal configuration. Removing the extension removes its browser-owned data; exported files remain wherever the user saved them.

Optional tab/session tools read titles and URLs after permission is granted. Recent Sites reads browsing history only when enabled and authorized. This information is not sent to NØVA or an external server. Tab audio indicators trigger fading of local music; audio content is not recorded for this function. The memory display reads only this page's JavaScript heap when the browser exposes it.

The optional browser companion injects a packaged isolated handle on permitted HTTP/HTTPS pages. Position and domain exclusions are local; per-tab hiding lasts for the browser session. Pulling/clicking the handle opens TikTok in a normal browser popup where TikTok's policy applies. The companion does not read general website text, inputs or account credentials.

User-triggered direct video PiP finds a video element on the selected page, moves it into a native browser Picture-in-Picture window, exposes playback controls and restores the element when the window closes. The source tab must remain open. The separate live-preview mode captures only the tab selected by the user under optional tabCapture permission. Preview data stays on the device, is never uploaded, and is released on close. Optional preview audio starts muted.

Spotify Web integration is enabled by default. After the browser grants the two required site permissions at installation/update, a packaged script on open.spotify.com reads displayed song title, artist, duration, playback position and play/pause state. State is held in session storage for synchronized lyrics. It does not read credentials, tokens, cookies or private account details. The optional Windows PowerShell bridge runs outside the extension. After manual per-user registration and nativeMessaging authorization, the browser launches a packaged PowerShell script through Native Messaging. It reads only Spotify metadata from Windows media sessions and stores it in browser session storage. It does not capture screen/audio, read credentials, open a network server or contact the publisher. Disabling disconnects the process; the provided uninstall command removes the registration. Desktop song metadata is sent to LRCLIB while online lyrics is enabled.

Online lyrics is enabled by default in 1.5.6. You can disable Spotify or online lyrics independently in Music. Song title, artist and duration are sent to [LRCLIB](https://lrclib.net) for synchronized lyrics. The service receives normal network information including the IP address. Local LRC works offline. Availability depends on the song/service; word reveal may be estimated from line timings.

A requested font download sends the entered family name to fonts.googleapis.com and downloads font bytes from fonts.gstatic.com. Those services receive normal network information including IP address. Fonts are cached locally; uploaded font files are not sent anywhere.

GitHub and Guns creator photos are bundled locally. About/footer do not request those websites merely to display the bundled photos. Opening a profile link navigates to that website. Existing configurations may retain optional Guns avatar synchronization, which requests Guns host access and reads only the public creator avatar URL when visiting guns.lol/xtufa7. The worker downloads that public image from r2.guns.lol without credentials and sends the CDN its own website Referer, limited by a temporary rule to the exact extension image request. The saved photo and sync time remain local. The About upload/follow buttons were removed in 1.5; existing cached avatars remain local. Guns receives normal website/download network information including IP address.

Tracker blocking uses bundled rules after opt-in and optional host authorization. It does not read network request bodies or download remote rule lists. Exceptions are stored locally. It does not guarantee prevention of all tracking.

Searches and links navigate to the user's chosen destination, whose policy applies. Optional destination favicons contact their corresponding website. Browser permissions can be revoked in the extension's site-access controls; NØVA also provides revoke controls. Clipboard actions copy only user-requested visible text. The developer branding gate never stores, exports or transmits the entered password; it is a convenience gate, not protection against modification of the extension source.

The publisher must keep this policy aligned with the actual release and provide a public HTTPS policy URL when submitting to the Store.
Firefox/Zen packages declare the required website-content data category at installation, for the default Spotify/lyrics feature. No Firefox-only fields are sent to Chromium permissions APIs. [Firefox consent documentation](https://extensionworkshop.com/documentation/develop/firefox-builtin-data-consent/). Optional integrations and permissions remain user-controlled. Local music uses a dedicated extension audio tab on these browsers.

The optional Windows setup reads local browser extension registrations to discover NØVA IDs, then registers exact allowed extension IDs for supported browsers. It does not edit browser preferences, read history/cookies, authorize wildcard origins, or send discovery data over the network. Run setup.cmd once; automatic startup is controlled by Desktop bridge in each browser.
